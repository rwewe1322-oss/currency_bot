# Currency and Weather Bot

Telegram-бот, который показывает курс доллара и погоду в Москве.

## Функционал
- Команда `/start` — приветствие и кнопки.
- Кнопка "Курс доллара" — получает актуальный курс через API.
- Кнопка "Погода в Москве" — получает данные о погоде через wttr.in.

## Стек технологий
- Python
- pyTelegramBotAPI
- requests

## Как запустить
1. Установить библиотеки:
   `pip install pytelegrambotapi requests`
2. Вставить свой токен в переменную `token` в файле `bot.py`.
3. Запустить:
   `python bot.py`
